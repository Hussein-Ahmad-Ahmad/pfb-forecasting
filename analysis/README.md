# Analysis utilities

Campaign analysis is implemented in `scripts/paper/analyze_review_gap_results.py`
and `experiments/controlled_addons/analyze.py`. Historical analysis utilities are
retained here. Compact inputs and results are under `results_summary/`.

Check the result provenance before combining cohorts or interpreting paired
effects. Temporal prefixes are partition-sensitivity experiments, and factorial
interval containment is descriptive rather than adjusted equivalence.
